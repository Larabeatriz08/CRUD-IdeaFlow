# IdeaFlow

IdeaFlow é uma aplicação web desenvolvida com HTML, CSS e JavaScript puro para gerenciamento de ideias de startup.

O projeto possui sistema de login e um CRUD completo para adicionar, visualizar, editar e remover ideias dinamicamente.


## Funcionalidades

- Login com validação
- Adicionar ideias no início da lista
- Adicionar ideias no final da lista
- Editar ideias
- Remover ideias
- Atualização dinâmica da interface
