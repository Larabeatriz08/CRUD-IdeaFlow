# IAs Consultadas

## 1. ChatGPT

### Prompt utilizado

Crie uma aplicação web utilizando HTML, CSS e JavaScript puro que possua uma tela de login e um sistema CRUD completo.

O tema da aplicação deve ser uma lista de ideias de startup.

Requisitos obrigatórios:
- Login com usuário "aluno" e senha "fiap2025"
- Validar campos vazios
- Exibir mensagens de erro na tela
- CRUD completo
- Adicionar item no início e no final da lista
- Editar item individualmente
- Remover item por índice
- Utilizar apenas array de strings
- Não utilizar frameworks
- Organizar a lógica em funções nomeadas

### Problemas encontrados

A resposta estava muito extensa e utilizava algumas funções mais avançadas do JavaScript.

# IA Escolhida

A IA escolhida como base foi o ChatGPT.

Motivos:
- Melhor organização das funções
- Estrutura mais clara
- Código mais fácil de adaptar
- Atendeu a maior parte dos requisitos obrigatórios
